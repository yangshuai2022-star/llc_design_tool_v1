Power Design Toolkit / LLC Design Tool V8.1
Release Candidate Verification Report
Date: 2026-09-03

======================================================================
1. RELEASE SCOPE
======================================================================

Implemented in this package:
  - V8.0 common LLC multi-fidelity analysis contracts and Golden Waveform layer
  - V8.1 nonlinear multi-harmonic harmonic-balance solver
  - Exact rectifier commutation zero-crossing projection for continuous-clamp branch
  - Explicit regularized fallback at light-load/discontinuous branch transitions
  - FHA / HB / switched-periodic TD orchestration and error comparison
  - Common CSV / JSON / Markdown / waveform export
  - CLI integration: waveforms --mode fha|hb, model-compare
  - GUI source integration: FHA/HB/TD page and HB waveform command
  - Full-bridge and half-bridge HB paths

Not claimed as implemented in this release:
  - V8 enhanced transformer winding/core/parasitic/thermal solver
  - Nonlinear MOSFET Coss/Qoss commutation model
  - Digital SR timing/LUT/loss
  - 2-phase 90-degree and 3-phase 120-degree interleaved LLC pages
  - Corner/sensitivity/measurement calibration

======================================================================
9. KNOWN NUMERICAL / PHYSICAL BOUNDARIES
======================================================================

1. Exact HB currently models the ideal continuously clamped full-bridge
   rectifier/SR branch. Around light-load discontinuous topology transitions,
   the solver may use the explicitly reported regularized branch.

2. The switched TD reference is the existing ideal-switching periodic model.
   It is not a nonlinear-Coss or semiconductor-recovery SPICE model.

3. The primary bridge deadtime is represented in bridge/gate waveforms. Full
   nonlinear Coss/Qoss charge commutation is deferred.

4. Winding capacitance, detailed leakage network, device recovery and the
   planned V8 magnetic feedback-to-electrical model are deferred.

5. HB/TD agreement is a model cross-check, not a substitute for PLECS/SPICE
   and hardware correlation once real parasitics are introduced.
