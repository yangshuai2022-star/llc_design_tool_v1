# Power Design Toolkit V9.1.0

发布日期：2026-09-09。

## 本版更新

- LLC 工作区工具栏新增“导出公式 PDF”，输出公式、数值代入、单位、结果、工况表、损耗清单和模型边界。自动设计与用户自定义 Lr/Cr/Lm 使用各自的推导路径。
- 新增“保存工程 JSON”：记录格式版本、工具版本、输入、计算摘要和数据来源；旧参数文件仍可加载。
- 修复版本号不一致导致的重复更新提示。自动检查每次启动只运行一次，同一已忽略版本不会反复提醒，手动检查仍可使用。
- 修复 Digital Control Tools 在初始化页签时提前刷新未创建控件的问题。
- 补齐 openpyxl、httpx2 依赖，新增本地报告/API、公式 PDF、工程保存、数据来源和 GUI 启动回归。

## 使用

下载对应系统的 ZIP，解压后启动 PowerDesignTool。进入 LLC 工作区后，设置参数并点击“导出公式 PDF”。“保存工程 JSON”用于保存当前输入及可用的计算摘要。

源码安装：`python -m pip install -e ".[gui,dev,web]"`。虚拟环境可放在项目外的公共环境目录；不同软件共用前应确认依赖兼容。

## 验证与限制

本机 Python 3.12 完整测试：315 passed、2 xfailed；示例公式 PDF 共 8 页，已逐页检查。跨平台安装包由 GitHub Actions 构建，自动构建不代表所有窗口交互已人工验证。

公式计算书目前覆盖 LLC 系统设计主链路；磁性件的 FFT/iGSE 等算法显示方法与汇总结果，尚未导出每个谐波及每轮迭代的完整明细。报告采用英文及纯文本数学符号，后续可进一步完善二维数学排版。

三相共享整流桥 LLC 仍只支持平衡相参数；两项补偿器 API 测试仍为预期失败。器件、磁芯、材料和成本记录为工程参考数据；C99 提供控制内核与 BSP 模板，实际硬件配置需结合目标板实现。工程 JSON 尚不包含完整的多版本历史管理。

本次发布桌面安装包，不部署 Web 服务；PFC、Vienna、DAB Web 占位页及 DAB 计算模块不在本次发布实现范围内。
